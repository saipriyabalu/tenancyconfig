# OCI Enterprise AI Evaluation PoC — Customer Guide 

## What is OCI Enterprise AI

End-to-end developer offering that brings together the capabilities needed to build, manage, and deploy AI workloads—helping teams move from experimentation to production with greater speed and confidence, regardless of structured or unstructured data sources.

## Model Access

An interface in the Oracle Cloud Console for exploring the hosted pretrained and custom models without writing a single line of code. Use the playground to test your use cases and refine prompts and parameters. When you're happy with the results, copy the generated code or use the model's endpoint to integrate Generative AI into your applications.

OCI Generative AI supports core model tasks such as:

- Chat for conversational generation
- Embeddings for semantic search, recommendation, classification, and clustering
- Rerank for ordering documents by relevance to a query

## Model Usage Options

OCI Generative AI supports multiple ways to use models:

- **Pretrained hosted models** - Managed inference through OCI with no infrastructure maintenance
- **Imported models** - Support for custom model deployment in your environment
- **On-demand mode** - Shared managed access for cost-effective experimentation
- **Dedicated mode** - Isolated model serving on dedicated AI clusters for production workloads

These options let you move from experimentation to production while selecting the level of control, performance isolation, and infrastructure management that fits your workload.

## Model Infrastructure and Management

Enterprise AI Models in OCI Generative AI are supported by deployment and management resources:

- **Dedicated AI Clusters** - Isolated model hosting for production workloads
- **Endpoints** - Scalable serving endpoints for model traffic
- **Private Endpoints** - Secure network access within your VCN
- **Regional availability** - Models deployed across multiple OCI regions
- **Performance guidance** - Optimizations for production workloads
- **Cost management** - Tools for monitoring and optimizing AI infrastructure costs

## Getting Started

To begin using OCI Enterprise AI:
1. Access the OCI Console and navigate to Generative AI
2. Explore available models in the Model Access playground
3. Test your use cases and refine prompts
4. Use the generated code or model endpoints in your applications
5. Scale from on-demand to dedicated mode as needed

For detailed documentation and examples, visit the [OCI Enterprise AI documentation](https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm).
